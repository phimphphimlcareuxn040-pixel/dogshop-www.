ศูนย์มัลติมีเดีย & ระบบโอเวอร์เลย์ (Interactive Overlays) 🎥🔊🌐

ทดสอบการแสดงผล รูปภาพ วิดีโอ เสียงเห่าสังเคราะห์ และข้อมูลสุนัขจาก API แบบเต็มรูปแบบ

🔊 1. แผงควบคุมเสียงเห่าน้องหมา (Audio Bark Synth Overlay)

จำลองเสียงเห่าสุนัขด้วย Web Audio API โดยไม่ต้องพึ่งไฟล์ภายนอก คุณสามารถกดทดลองฟังเสียงเห่าโทนต่างๆ ผ่าน Overlay Modal ได้ทันที!

🎥 2. วิดีโอเพลเยอร์โอเวอร์เลย์ (HTML5 Video Modal Overlay)

คลิกที่วิดีโอน้องหมาเพื่อแสดงผลบน Popup Window ความละเอียดสูง พร้อมระบบควบคุมการเล่นและเสียง
